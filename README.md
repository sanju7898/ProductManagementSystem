# Product Management System

A web-based Product Management System built using ASP.NET Core MVC and Entity Framework Core.

## Technologies Used

* C#
* ASP.NET Core MVC (.NET 9)
* Entity Framework Core
* SQL Server
* HTML, CSS, JavaScript, Bootstrap

## Key Features

* Product management (CRUD operations)
* Category management
* Customer management
* Supplier management
* Dashboard and data summaries
* Search functionality
* Order management
* Report management

## Project Structure

* Controllers — Handles application requests
* Models — Defines application data
* Data — Database context
* Services — Business logic
* ViewModels — Data for views
* Views — User interface
* Migrations — Database schema changes

## Getting Started

1. Clone or download this repository.
2. Open the solution in Visual Studio.
3. Update the database connection string in `appsettings.json` for your SQL Server.
4. Apply Entity Framework Core migrations if required.
5. Run the application.
